# 知流 NoteFlow 官网

官网用完整知流工作台演示同一篇笔记从输入到保存。滚动推进录屏，向上滚可以回看。写作流程末尾可展开 4K 实录，后续展示阅读目录、整篇修改、选区改写和长期记忆。

## 截图来源

录屏和截图均来自知流前端 `34396e7` 在本机隔离的 FastAPI / PostgreSQL 环境中运行的界面。使用测试账号、Docker 示例笔记和测试写作偏好。截图只做裁切、缩放和 WebP 压缩。

- `write-scroll.mp4`（1920×1080）与 `create-note-4k.mp4`（3840×2160）来自同一次完整工作台录制。源画面为 4320×2430，两份 H.264 成片均为 18.25 秒。全程保留完整视口，缩短等待，未叠加字幕和自制界面。滚动版每 0.3 秒一个关键帧。页面先加载完整的滚动版文件，再在浏览器中按滚动定位，兼容托管返回整段视频的情况。
- `journey-*.webp` 是同次录制的完整帧，用于首帧和关闭脚本、减少动态效果或视频故障时的逐步浏览。
- `outline.webp` 是阅读笔记时展开的章节目录，`outline-detail.webp` 裁自同一张实录。
- `edit.webp` 是 AI 生成整篇修改后的原文对照。`selection.webp` 是编辑器内「AI 改一下」的实际输出，`selection-detail.webp` 是放大的原始面板。
- `memory-4k.mp4` 从空的测试记忆开始录制：在实际对话中请知流保存柠檬茶举例偏好，打开记忆摘要确认，再建新对话解释 API 限流。核对了两次对话 ID、保存记录和最近使用时间；新问题没有复述偏好。使用项目的本机记忆引擎、实际模型和测试账号。`memory-poster.webp` 来自最后一段真实对话。
- `zhiliu.svg` 取自项目的 `public/favicon.svg`。

## 本地预览和托管

从仓库根目录运行：

```sh
python3 -m http.server 4178 --bind 127.0.0.1 --directory website
```

打开 <http://127.0.0.1:4178/>。发布时将 `index.html`、`styles.css`、`film.js`、`journey.js` 与 `assets/` 放到同一静态目录。资源使用相对路径，可部署到独立域名或子路径。回退可以恢复上一版静态目录，或在托管平台切回相应版本。项目仓库提供工作台的运行说明。
