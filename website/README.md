# 知流 NoteFlow 官网

官网介绍知流的笔记编辑、搜索和带出处的 AI 问答。互动演示使用三篇示例笔记和两条预写答案。用户编辑只保存在当前页面内存中，刷新后恢复默认内容。演示可直接通过静态托管访问。

## 本地预览

从仓库根目录运行：

```sh
python3 -m http.server 4178 --bind 127.0.0.1 --directory website
```

浏览器打开 <http://127.0.0.1:4178/>。页面适配手机和桌面，交互使用浏览器原生输入框、弹窗和展开组件。

## 托管

将 `index.html`、`styles.css`、`demo.js` 与 `assets/` 一起发布到同一静态目录。CSS、JavaScript 和图片使用相对路径，可以托管在独立域名或子路径。上线后检查 HTTPS、静态资源和所有演示入口。回退时恢复上一版静态目录或在托管平台切回上一版。正式站点地址与工作台链接应在确定部署目的地后更新。

首屏插图由内置 ImageGen 生成，WebP 有两种尺寸。提示词要点是浅蓝半透明纸带在三张留白的笔记纸间流动，背景接近白色，柔和自然光，无文字或标志。产品图标取自仓库的 `public/favicon.svg`。
